# 首轮 overlapping 实验（2026-09-16）

结论：前文重叠能改善个别术语，但仅靠提示“前文不输出”不能可靠避免重复；当前不接入默认字幕流程。

使用此前两段课堂录音的同一批 21 个 ASR 英文切片，Hy-MT2 1.8B Q4、CPU 4 线程。每个片段依次运行基线和重叠条件，后者带此前最多 16 个按空格分隔的英文词，只要求翻译当前片段。目标片段本身不重复加入显示队列。每段使用相同模型参数，输入只在本机处理。

| 条件 | 请求数 | 单请求推理耗时中位数 | 输出保护报错 |
|---|---:|---:|---:|
| 无上下文 | 21 | 2.60 秒 | 0 |
| 前文最多 16 词 | 21 | 3.44 秒 | 0 |

包含各录音无前文的首片段；不含模型加载，但包含 prompt 计算。约增加 32% 是本次观测，顺序固定、缓存影响和后台负载没有隔离，不作为普遍性能结论。这是离线文本翻译对照，不是系统声音积压测试。

人工检查发现：圆盘/质量等词在某些片段更贴切；另一些片段把前一片段的操作描述或引导语带入译文，至少在 source A 的零基索引 6、7、9 和 source B 的索引 2 发现明显前文泄漏。该现象没有触发模型的异常保护，说明“不报错”不代表片段边界正确。ASR 误词和部分 volume 误译仍然存在。没有人工参考译文，不报告准确率。

本轮仅测试**左侧文字上下文**，未测试音频重叠、向后等待少量词、或完整翻译窗口回写。不能据此断言所有 overlapping 方案无效。下一轮应把最后一条字幕作为可修订窗口、按源文本范围替换整条译文，并设置等待/重译上限；不能靠删除相似中文前缀来猜测对齐。

复现：安装 Hy-MT2 后运行 `python scripts/compare_overlap.py <本地片段JSON>`。JSON 结构为 `{"sources": [{"id": "sample", "chunks": ["English fragment one", "English fragment two"]}]}`。逐段结果和摘要输出到被 Git/源码包排除的 `diagnostics`。不要将私人课堂正文作为公共测试样本提交。
